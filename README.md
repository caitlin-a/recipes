# recipes

Personal recipe collection. I take no responsibility for poisoning you.

Every recipe starts with `status`, `diet`, `type` and `contains` tags. Recipes I haven't cooked yet live in `untested/`, so don't take them as recommendations. Search the repo for `status: to_try` to find them, `diet: vegan` for the vegan ones, `adaptable: [vegan]` for ones that are easy to make vegan, or `type: dessert` for something sweet.
